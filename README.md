# ci-cd-lab

Навчальний PHP-проєкт, який розвивається протягом лабораторних робіт з дисципліни «Технології розробки програмного забезпечення».

## Мета

Продемонструвати повний цикл розробки невеликого PHP-застосунку: керування версіями, автоматичні перевірки якості коду та безперервну інтеграцію.

## Що буде реалізовано

- сервісний шар із бізнес-логікою на PHP;
- модульні тести на PHPUnit;
- статичний аналіз і форматування коду за допомогою Laravel Pint;
- CI-пайплайн на GitHub Actions.

# ci-cd-lab

Навчальний PHP-проєкт, який розвивається протягом лабораторних робіт з дисципліни «Технології розробки програмного забезпечення».

## Мета

Продемонструвати повний цикл розробки невеликого PHP-застосунку: керування версіями, автоматичні перевірки якості коду та безперервну інтеграцію.

## Функціонал (план)

- сервісний шар із бізнес-логікою на PHP (розрахунок вартості замовлення, знижки);
- модульні тести на PHPUnit;
- статичний аналіз і форматування коду за допомогою Laravel Pint;
- CI-пайплайн на GitHub Actions: встановлення залежностей, лінт, тести;
- захист головної гілки та обов'язкові перевірки перед злиттям.

## Структура проєкту (планова)

```
.
├── .github/
│   ├── workflows/
│   │   └── php-ci.yml
│   └── PULL_REQUEST_TEMPLATE.md
├── app/
│   └── Services/
│       └── Calculator.php
├── tests/
│   └── Unit/
│       └── CalculatorTest.php
├── .gitignore
├── composer.json
└── README.md
```

## Локальний запуск

Потрібні PHP 8.2+ та Composer.

```bash
composer install
./vendor/bin/pint --test
./vendor/bin/phpunit tests/Unit
```
